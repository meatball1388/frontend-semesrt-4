# Fullstack Development - Semester 4 (Practices 19-22)

Репозиторий содержит цикл практических работ по дисциплине «Фронтенд и бэкенд разработка», охватывающий проектирование баз данных, внедрение кэширования и настройку балансировки нагрузки.

## 🛠 Технологический стек
- **Runtime:** Node.js (Express)
- **Databases:** PostgreSQL (Relational), MongoDB (NoSQL)
- **Caching:** Redis
- **Infrastructure:** Docker, Docker Compose
- **Proxy & Load Balancing:** Nginx

---

## 📝 Обзор практических работ

### [Практика №19] Работа с реляционными СУБД (PostgreSQL)
Реализация REST API для управления пользователями с использованием SQL.
- Спроектирована схема таблицы `users` (ID, first_name, last_name, age, timestamps).
- Реализован полный цикл CRUD-операций.
- Изучены основы оптимизации запросов через индексы.

### [Практика №20] Работа с NoSQL СУБД (MongoDB)
Разработка альтернативной версии сервиса на базе документоориентированной модели.
- Работа с BSON-документами и гибкой структурой данных.
- Сравнение подходов SQL vs NoSQL при проектировании сущностей.

### [Практика №21] Кэширование с использованием Redis
Оптимизация производительности системы и снижение нагрузки на основную базу данных.
- Внедрена стратегия кэширования **Cache-Aside**.
- Установлен TTL (Time To Live) для кэша — 60 секунд.
- Реализован механизм автоматической инвалидации кэша при обновлении или удалении данных.

### [Практика №22] Балансировка нагрузки (Nginx)
Создание отказоустойчивой архитектуры приложения.
- Настройка Nginx в качестве Load Balancer для распределения трафика между двумя инстансами бэкенда.
- Настройка параметров отказоустойчивости: `max_fails` и `fail_timeout`.
- Полная оркестрация всех сервисов через Docker Compose.
